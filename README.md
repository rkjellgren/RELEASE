# RELEASE 

This repository contains files related to the RELEASE project (CSO HIPS/21/54). We are currently in the process of finalising our analysis, and in due course, we will upload R code and other materials here. Currently, we have only made the diagnostic and clinical codes used to identify mental ill-health and substance use-related service contacts available (see `RELEASE_MHSU_Codes.xlsx`). Each sheet represents a unique diagnostic/clinical coding system, and all codes are either flagged as `MH` (mental ill-health) or `SU` (substance use). The variable names `release_mh_bucket` and `release_su_bucket` are boolean, and if a code, for instance, is primarily related to mental ill-health, then `release_mh_bucket == TRUE`. In the ICD10 sheet, the variable `release_mhsu_bucket` simply means that the code is in either `release_mh_bucket` or `release_su_bucket`. Service contacts classified as dual diagnosis (`DD`) are simply the presence of at least one `MH` code and one `SU` code associated with one particular contact. See our [protocol paper]([url](https://ijpds.org/article/view/2971?articlesBySameAuthorPage=3)) for more information.
